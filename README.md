# Світ Гаррі Поттера

Навчальна робота: сайт за макетом Figma з даними зі
[hp-api.onrender.com](https://hp-api.onrender.com/). Ванільний JavaScript, без фреймворків,
збірка — Vite.

## Запуск

```bash
npm install
npm run dev
```

Перевірка готової збірки:

```bash
npm run build
npm run preview
```

## Що вміє

- Головна з кнопкою, яка розкриває блок вибору — три функції.
- **Студенти Гоґвортсу** — `/api/characters/students`
- **Співробітники Гоґвортсу** — `/api/characters/staff`
- **Персонажі в певному будинку** — `/api/characters/house/:house`, вкладки чотирьох будинків
- Панель з інформацією про персонажа при наведенні, фокусі з клавіатури або кліку
  на «Більше інформації».

Адреси у хеші: `#/students`, `#/staff`, `#/house/gryffindor`. Кнопка «назад» у браузері
працює, пряме посилання на будь-який екран відкривається одразу.

## Структура

```
index.html              hero і блок вибору — статична розмітка
src/main.js             роутер на hash
src/base.css            палітра, типографіка, кнопки
src/api/characters.js   запити до API + кеш у Map
src/lib/format.js       приведення значень до вигляду з макета
src/views/              list, card, details, houseTabs — кожен зі своїм CSS
```

CSS імпортується з JS (`import "./card.css"`) — так працює Vite, у голому браузері
без збірки це б не запрацювало.

## Що варто знати про дані

Макет намальовано на Гаррі, Герміоні та Рона, у яких заповнено все. У реальних даних
більшість полів порожні:

| Поле | Порожнє у |
|---|---|
| `image` | 412 з 437 (у студентів — 92 зі 103) |
| `house` | 302 |
| `patronus` | 419 |
| `wand` | 412 |

Тому:

- **`<img>` не створюється взагалі, якщо фото немає.** Порожній `src` пішов би запитом
  і дав 404 у консолі, а `onerror` тут не рятує — помилку вже записано до його виклику.
  Замість фото показується заглушка з CSS.
- Порожні рядки в картці та в панелі не малюються.
- Булеві значення форматуються **до** фільтрації, і фільтр порівнює з `""`, а не з
  істинністю, — інакше кожне `False` мовчки зникло б.

API віддає нижній регістр (`half-blood`), макет показує `Half-blood` — за це відповідає
`src/lib/format.js`.

## Чиста консоль

Вимога ТЗ. Перевірено на `npm run preview`: повний прохід усіма екранами — **жодного
повідомлення**, рівень Verbose.

Єдиний випадок, коли в консолі щось з'явиться, — якщо API справді недоступне: рядок
`net::ERR_NAME_NOT_RESOLVED` друкує сам браузер, подавити його з JS неможливо. Застосунок
при цьому показує текст помилки та кнопку «Спробувати ще раз», а не падає.

## Що ще не зроблено

Картинки з макета (фон Хогвартсу, сова, фото для блоку вибору, герби будинків) поки
замінені градієнтами та SVG-щитами — файл Figma відкрито лише на перегляд. Коли
експорти ляжуть у `public/img/`, розмітку міняти не доведеться.
